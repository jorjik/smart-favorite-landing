How to move Telegram Saved Messages into the bot

Telegram gives bots no access to your chats, so Saved Messages come over as a file: export them from Telegram Desktop and upload the archive to the mini app. Every saved message with a link becomes a note in the Telegram category, with the message caption as its title and no duplicates.

~5 minutes · free · file only, no account access

  1. Install Telegram Desktop

    Data export exists only in the desktop app for Windows, macOS or Linux. The mobile client and the web version cannot export — that is a Telegram limitation, not the bot's. Sign in with the same account you use on your phone.

  2. Open the data export

    In Telegram Desktop: Settings → Advanced settings → Export Telegram data. Older versions call the entry Export data.

  3. Keep only Saved Messages

    Untick everything and tick Saved Messages. Turn photos, videos and files off — the import needs links only, and the archive stays tiny.

  4. Pick JSON and All time

    Format JSON (HTML works too), range All time. Click Export and wait for the archive: a few minutes for thousands of messages.

  5. Upload the ZIP to the mini app

    Open Smart Favorite → Import, pick the Telegram Saved Messages source and upload the whole ZIP. The result.json inside is found automatically — no need to unzip.

What lands in the import

  • Links from your saved messages, together with the caption: it becomes the card title.
  • Service records and messages without links are skipped, so the notes stay clean.
  • Repeats, tracking parameters included, never create duplicates: the same link is not saved twice.
  • Photos, videos, files and link-less text are not imported: a note is a link, a title and a caption.

Frequent questions

Can I get Saved Messages without an export?

No. The Bot API does not let bots read chats, and a mini app has no access to them either: Telegram does not hand messages to a bot, even to its owner's. Exporting on a computer is the only way.

Why Telegram Desktop?

Only the desktop app can export data; the mobile client and the web version have no such option. Sign in with the same account and your Saved Messages are right there.

How many links fit in one import?

Up to 1000 links per import. If you have more, split the export by date range and upload the archives one by one: what is already saved counts as duplicates and is not saved twice.

The file is huge — is that normal?

With media ticked the ZIP can be gigabytes. Untick photos, videos and files: what remains is a few megabytes with a single result.json.

Can I undo the import?

Yes, the whole batch at once: every note goes to the trash and can be restored from there.
