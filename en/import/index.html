What happens to the file

  • The file is parsed in memory and is not stored on the server disk.
  • Links that already exist in your notes are skipped, so re-importing is safe.
  • The whole import can be undone with one button — the batch goes to the trash.
  • Post text and images from the export are not copied: a note is a link, a title and a caption.
