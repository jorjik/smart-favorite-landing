Browser bookmarks

How to export browser bookmarks and move them to Telegram

Every browser can export its bookmarks as one HTML file. Upload it to the mini app: links and titles become notes, and folders become rubrics.

~5 minutes · free · no OAuth, just a file

  1. Export bookmarks in Chrome or Edge

    Open chrome://bookmarks (or edge://favorites) → ⋮ → Export bookmarks. Save the HTML file.

  2. Export bookmarks in Firefox

    Open Library → Bookmarks → Manage bookmarks → Import and Backup → Export Bookmarks to HTML.

  3. Export bookmarks in Safari

    Choose File → Export → Bookmarks. Safari saves an HTML file with the same standard format.

  4. Upload to the mini app

    Open Smart Favorite → Import, choose Browser bookmarks and upload the HTML file (a ZIP also works).

  5. Keep or flatten folders

    Folders become separate rubrics by default. Bookmarks outside folders go to the rubric you pick. Turn off “Keep folders as rubrics” to put everything in one rubric.

What gets imported

  • Every bookmark URL and its title.
  • Folder names as rubrics, including nested folders.
  • Favicons, descriptions and browser history.
  • Bookmarks with JavaScript or internal browser URLs.

Common questions

Do folders transfer?

Yes, when “Keep folders as rubrics” is on. Each folder becomes a rubric; bookmarks outside folders go to the rubric selected in the mini app.

Does it work with another browser?

Yes. Chrome, Firefox, Safari and Edge all export the Netscape Bookmark File format, and the parser handles all of them the same way.

What if I have thousands of bookmarks?

One import takes up to 1000 links; the rest are reported as skipped. Upload the same file again: existing links are not duplicated and the next batch is imported.

Move your browser bookmarks in a couple of minutes

The file is not stored on disk, duplicates are skipped, and the whole import can be undone.
