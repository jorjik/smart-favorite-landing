# Smart Favorite — дизайн-система лендинга

Источник истины для `index.html` и `en/index.html`. Основа — скилл `ui-ux-pro-max` (v2.15.0), домены `landing` / `color` / `typography`; авто-паттерн «FAQ/Documentation Landing» и палитра Atkinson Hyperlegible отброшены как мисроут.

## 1. Продукт и паттерн

Telegram-бот «второй мозг»: сохраняет ссылки, фото, голос, видео; AI раскладывает по рубрикам и находит по фразе.

- **Паттерн:** Hero + скриншоты + фичи + цены + финальный CTA. Две CTA-точки: в hero и после блока цен.
- **Витрина:** реальные скриншоты мини-приложения — главный аргумент, не текст.
- **Целевое действие:** переход в @SmartFavoriteBot.

## 2. Стиль

**Dark AI-native + минимализм.** Тёмная база, один градиент (violet→teal) — только CTA и акцентные слова. Без стеклянных панелей, неона и разноцветных « AI-градиентов».

- Радиусы: 12px кнопки, 16px карточки, 999px бейджи.
- Тени: 1–2 слоя на карточках, без свечения.
- Иконки: только SVG (Lucide/Heroicons), 20–24px, `stroke-width: 1.75`, `aria-hidden="true"`. Эмодзи как иконки — запрещено.

## 3. Цвета

| Токен | Значение | Контраст | Применение |
|---|---|---|---|
| `--bg` | `#0b0d12` | — | фон страницы |
| `--surface` | `#161a25` | — | карточки, шапка, поля |
| `--border` | `#262c3d` | — | границы 1px |
| `--text` | `#e8ebf4` | 16.3:1 на bg | основной текст |
| `--text2` | `#c2c8d8` | 11.6:1 | лид, подзаголовки |
| `--muted` | `#9aa3b8` | 7.7:1 | подписи, мета |
| `--brand` | `#7c5cff` | 4.35:1 с белым ✗ | градиент, крупный текст, иконки |
| `--brand-strong` | `#6d4aff` | 5.15:1 с белым ✓ | фон кнопок |
| `--accent` | `#2dd4bf` | 10.4:1 | ссылки, Pro, успех |
| `--grad` | `linear-gradient(90deg,#7c5cff,#2dd4bf)` | — | CTA-фон, акцентные слова |

**Правило:** белый текст на `--brand` не проходит 4.5:1 (4.35). Для кнопок — `--brand-strong`; чистый `--brand` оставить градиенту, иконкам и крупным заголовкам.

## 4. Типографика

**Outfit** (заголовки) + **Work Sans** (текст):
`https://fonts.googleapis.com/css2?family=Outfit:wght@300..700&family=Work+Sans:wght@300..700&display=swap`

- H1: `clamp(30px,4.6vw,46px)/1.12`, вес 700, `letter-spacing:-0.02em`.
- Лид: `clamp(16px,2vw,19px)/1.55`, `--text2`, max-width 540px.
- Body: 16px/1.6. Минимум 13px.
- H2 секций: 24–30px/1.2, вес 600.
- Фолбэк: `-apple-system, "Segoe UI", Roboto, sans-serif`.

## 5. Сетка и отступы

- Контейнер `max-width: 1080px`, паддинги 20px.
- Шкала: 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96.
- Секции: 64px сверху / 48px снизу (десктоп), 40/32 (мобайл).
- Брейкпоинты: 375 / 768 / 1024 / 1440. Hero: `1.15fr .85fr` до 900px, далее в одну колонку.

## 6. Компоненты

**Кнопки.** Высота 44px (тач-цель ≥44×44), паддинг 11×20, радиус 12, вес 600, переход 150 мс.
- Primary: фон `--brand-strong`, текст `#fff`, hover `filter: brightness(1.08)`.
- Ghost: 1px `--border`, текст `--text`, hover фон `--surface`.
- Focus: `outline: 2px solid var(--accent)`, `outline-offset: 2px` — всегда виден.

**Карточки.** `--surface`, border `--border`, радиус 16, паддинг 20–24; hover: border `#33405c` + `translateY(-2px)`, 180 мс.

**Бейджи.** Радиус 999, border `--border`, 13px, `--muted`. Pro-чип: `--accent` на 12% + текст `--accent`.

**Цены.** Две карточки: Free (`--surface`) и Pro (`--surface` + 1px `--brand-strong` border + бейдж «21 день в подарок»). Цена 32–40px, `font-variant-numeric: tabular-nums`.

**Скриншоты.** Горизонтальный скролл `scroll-snap-type: x mandatory`, точки-индикаторы, стрелки на десктопе. Автопрокрутка либо выключена, либо с паузой на hover/focus/`prefers-reduced-motion`.

## 7. Движение

- 150–250 мс, `ease-out` на вход, `ease-in` на выход.
- Анимировать только `transform` / `opacity`.
- Обязателен `@media (prefers-reduced-motion: reduce)`.
- Hover — не единственный признак кликабельности.

## 8. Чек-лист перед публикацией

- [ ] Контраст текста ≥ 4.5:1, крупного (≥24px) и границ контролов ≥ 3:1
- [ ] Видимый focus у всех ссылок и кнопок
- [ ] Тач-цели ≥ 44×44, отступы ≥ 8px
- [ ] Только SVG-иконки, без эмодзи
- [ ] `alt` у скриншотов — про пользу, не «изображение»
- [ ] Проверено на 375 / 768 / 1024 / 1440
- [ ] Изображения WebP/AVIF, `loading="lazy"`, зарезервированные размеры (CLS < 0.1)
- [ ] `prefers-reduced-motion` уважается
