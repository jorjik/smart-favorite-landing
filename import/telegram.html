Как перенести «Избранное» из Telegram в бота

Telegram не отдаёт ботам переписку, поэтому «Избранное» переносится файлом: сохраните выгрузку Telegram Desktop и загрузите её в мини-приложение. Каждое сохранённое сообщение со ссылкой станет заметкой с рубрикой «Telegram» — с подписью из сообщения и без дублей.

~5 минут · бесплатно · только файл, доступ к аккаунту не нужен

  1. Установите Telegram Desktop

    Экспорт данных есть только в десктопном приложении для Windows, macOS или Linux. С телефона и из веб-версии выгрузку сделать нельзя — это ограничение Telegram, а не бота. Войдите тем же аккаунтом, что и на телефоне.

  2. Откройте экспорт данных

    В Telegram Desktop: «Настройки» → «Продвинутые настройки» → «Экспорт данных Telegram». В старых версиях пункт называется просто «Экспорт данных».

  3. Оставьте только «Избранное»

    Снимите все галочки и отметьте «Избранное» (Saved Messages). Фото, видео и файлы выключите — для импорта нужны только ссылки, и архив получится крошечным.

  4. Выберите JSON и «За всё время»

    Формат — JSON (подойдёт и HTML). Диапазон — «За всё время». Нажмите «Экспортировать» и дождитесь архива: на тысячах сообщений это несколько минут.

  5. Загрузите ZIP в мини-приложение

    Откройте Smart Favorite → «Импорт», выберите источник «Избранное Telegram» и укажите ZIP целиком. Файл result.json внутри найдётся сам — распаковывать не нужно.

Что попадёт в импорт

  • Ссылки из сохранённых сообщений — вместе с подписью: она станет заголовком карточки.
  • Служебные записи и сообщения без ссылок пропускаются — мусора в заметках не будет.
  • Повторы, в том числе с utm-метками, не создают дублей: та же ссылка второй раз не сохраняется.
  • Фото, видео, файлы и текст без ссылок не переносятся: заметка — это ссылка, заголовок и подпись.

Частые вопросы

Можно ли забрать «Избранное» без экспорта?

Нет. Bot API не даёт ботам читать переписку, а мини-приложение не имеет доступа к чатам: Telegram не отдаёт сообщения даже владельцу через бота. Экспорт с компьютера — единственный способ.

Почему нужен именно Telegram Desktop?

Выгрузку умеет только десктопное приложение: в мобильном клиенте и в веб-версии такого пункта нет. Скачайте Telegram Desktop, войдите тем же аккаунтом — «Избранное» будет то же самое.

Сколько ссылок влезет за один раз?

До 1000 ссылок за импорт. Если в «Избранном» больше, разбейте экспорт по диапазону дат и загрузите архивы по очереди: уже сохранённое посчитается дублями и не задвоится.

Файл получился большой — это нормально?

Если в экспорте остались медиа, ZIP бывает на гигабайты. Снимите галочки с фото, видео и файлов — останется несколько мегабайт с одним result.json.

Импорт можно отменить?

Да, целиком: вся пачка уйдёт в корзину, откуда заметки восстанавливаются.
