Закладки браузера

Как перенести закладки браузера в Telegram

Любой браузер умеет отдавать закладки одним HTML-файлом. Загрузите его в мини-приложение — ссылки и названия станут заметками, а папки заменит выбранная рубрика.

~5 минут · работает с Chrome, Firefox, Safari, Edge

  1. Экспортируйте закладки

    Chrome: chrome://bookmarks → ⋮ → «Экспорт закладок».
    Firefox: «Библиотека» → «Закладки» → «Управление» → «Импорт и резервные копии» → «Экспорт в HTML».
    Safari: «Файл» → «Экспорт» → «Закладки».
    Edge: edge://favorites → ⋯ → «Экспорт избранного».

  2. Выберите рубрику заранее

    Структура папок при импорте не сохраняется. Если хотите разложить закладки по темам, сначала импортируйте всё в одну рубрику — а потом переносите нужное пачками на экране разбора.

  3. Загрузите HTML в мини-приложение

    Откройте Smart Favorite → «Импорт», выберите «Закладки браузера» и укажите файл .html. Название закладки станет заголовком заметки.

Что попадёт в импорт

  • Все http(s)-ссылки из файла закладок.
  • Названия закладок — как заголовки заметок.
  • Служебные адреса вроде chrome:// отбрасываются, дубли схлопываются.
  • Папки, favicons и описания закладок.

Частые вопросы

Переносятся ли папки закладок?

Нет. Все закладки попадают в одну рубрику, выбранную при импорте. Разложить точнее можно позже: на экране «Разобрать импортированное» выделяйте пачки и переносите в нужные рубрики.

Подойдёт ли экспорт из другого браузера?

Да, формат HTML общий (Netscape Bookmark File). Не важно, из какого браузера файл — импорт разберёт его одинаково.

А если закладок тысячи?

За один импорт берётся до 1000 ссылок, остальное честно считается пропущенным. Загрузите файл повторно: уже добавленные ссылки не задублируются, а в лимит попадут следующие.

Превратите закладки в базу заметок

Файл не сохраняется на диске, дубли не создаются, импорт можно отменить целиком.
